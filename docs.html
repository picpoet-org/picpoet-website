使用说明

从一张照片，
开始一份创作。

先连接模型，再选择照片。这里说明如何生成、保存、回看，以及每一步的数据去向。

也可以直接在线创作

打开网页版，注册并验证邮箱后上传照片，使用账户的官方生成次数。完成后下载纯诗词分享图，无需自行配置模型。图片在浏览器重编码以移除原图 EXIF，点击生成后才上传至官方服务及其模型服务；分享图在浏览器绘制，不包含原照片。服务端结果限时保存，请及时下载。

准备

安装与平台

在下载页选择适合设备的安装包，并核对系统要求。尚未发布的平台会明确标注。

Android 客户端要求 Android 8.0 及以上；保存副本到系统相册需要 Android 10 及以上。OpenHarmony、Linux、macOS 与 Windows 的系统版本、架构及安装方式，以对应发布包说明为准。

查看 Android 发布状态

第一步

连接你选择的模型

  1. 进入客户端设置，填写模型服务提供的 API key 与 Base URL。
  2. 使用模型探测功能，读取服务可提供的模型，并选择支持图像输入的视觉模型。
  3. 确认服务可访问、账号额度与计费规则，再开始照片创作。

Picpoet 使用兼容 OpenAI 接口的模型服务。探测到模型并不代表所有模型都支持图像，请结合服务商说明选择。连接本地模型时，需要自行运行兼容的视觉模型服务，并确保当前设备可访问该地址。

先了解照片会发往哪里

Base URL 决定请求发往的服务。使用云端模型时，所选照片及生成所需内容会发送给该服务；请确认地址可信，妥善保管 API key。

查看模型费用说明 →

第二步

为照片选择一种表达

选择一张照片，按需要选择创作类型：

  • 诗：以照片为灵感创作诗句。
  • 词：以照片为灵感创作词作。
  • 纯照片信息：只生成照片标题、描述与标签。

生成后先阅读结果，核对描述与标签是否符合画面。标题与正文支持复制，可以将文字用于自己的记录或分享。模型可能误解画面，生成内容应由你确认。

第三步

保存副本，或选择覆写

照片信息可写入元数据。请根据是否需要保留原图，选择对应保存方式。

保存副本

另存一份带有元数据的照片，保留源文件。Android 保存到系统相册需要 Android 10 及以上。

覆写源文件元数据

在支持的平台与照片来源上，明确选择后更新原图元数据。Android 需要 10 及以上，并可能需要系统授权。

照片来源、文件格式与系统权限会影响写入能力。部分云端或图库来源无法直接覆写，可以选择保存副本。覆写前建议备份原图，并在保存后核对结果。

创作之后

回看历史，也把诗意分享出去

  • 搜索与详情：在本机历史中检索记录，打开详情回看创作内容。
  • 查看原图：从记录打开对应原图；原图需要仍然存在且可访问。
  • 删除记录：按需整理本机历史。删除本机记录并不等于删除模型服务商可能保留的数据。
  • PNG 分享图：将照片与创作文字制作成图片，供保存与分享。

本机历史不是云端备份。更换设备、清理应用数据或卸载前，请自行备份需要保留的内容。

界面语言与诗词语言，分别设置

界面支持七种语言：简体中文、繁體中文、英语、日语、韩语、越南语、泰语。

诗词内容支持简体和繁体中文，默认繁体。界面语言与诗词内容语言分别设置，切换界面语言不代表诗词会改用该语言生成。

本机保存，不等于全程离线

历史记录保存在本机，但生成过程取决于你配置的模型服务。请把“数据存在哪里”与“请求发往哪里”分开理解。

使用云端模型
所选照片及生成所需内容会发送至配置的模型服务。数据保留、使用方式与费用由该服务的政策决定；请在发送前阅读并确认。
使用本地模型
需要自行部署兼容的视觉模型服务。数据是否离开设备，取决于服务部署位置、配置及其是否继续调用上游服务。
更新与其他联网行为
Android 客户端启动时的每日自动更新检查、设置中的手动检查，以及模型探测都可能联网。本机历史不意味着应用完全不联网。
照片与分享
发送前留意照片中的人脸、位置等个人信息。分享 PNG 图片、照片副本或原图前，确认愿意公开的文字和元数据范围。
