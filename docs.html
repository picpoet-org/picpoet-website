使用说明

网站与客户端，
按各自能力使用。

网站提供官方在线创作、账户历史与次数购买；客户端可连接自备模型，也可在启用官方服务后使用账户次数。两边都能生成纯诗词分享图，但历史、保存与设置并不互通。

网站

在线创作、作品与次数

网站面向浏览器：用已验证邮箱登录后，可在 在线创作 提交照片、在 我的作品 回看历史，并在 个人中心 查看余额、套餐与订单。

  • 固定使用官方生成服务与账户次数，不提供自备 API key 或本地模型配置。
  • 没有游客创作入口；未登录可浏览首页、使用说明、费用说明和下载页。
  • 网站历史属于账户，不与客户端本机历史自动同步。
打开在线创作登录 / 注册

选一张照片，提交官方生成

  1. 使用邮箱注册，完成验证码验证后登录。
  2. 在创作页选择一张 JPEG、PNG、WebP 或 GIF。选图后只在浏览器本地预览和处理，不会立刻上传。
  3. 点击生成后，浏览器将照片重编码为 JPEG、移除原图 EXIF，再提交官方异步任务。
  4. 等待结果时可以暂停本页查询；服务端任务不会因此取消。也可继续查询原任务，或按同一编号重试。

原图最多 25 MiB、4000 万像素；本地会缩至长边 2048px，上传仍最多 10 MiB。GIF 只处理首帧。网站不提供诗词体裁、韵书或照片元数据偏好设置，生成参数使用官方默认值。

结果请及时下载

服务端结果限时可取。需要长期保留时，请下载诗词正文或分享图；不要只依赖页面停留。

在我的作品里回看

历史功能启用后，新提交且成功的官方任务会写入账户作品集：保留压缩照片与诗词，默认 90 天，可提前永久删除。不会保存原图，也不会回填旧任务。

  • 作品页支持分页浏览、打开详情、查看压缩照片与完整诗词。
  • 详情可生成纯诗词分享图并下载；永久删除前会再次确认。
  • 历史尚未启用时，页面会提示“历史尚未启用”，当前生成与下载仍可继续。

查看次数，按需购买

个人中心显示邮箱、验证状态、免费与付费剩余次数，以及服务端套餐与订单。套餐价格来自服务端；下单后打开支付宝电脑网站支付或手机网站支付收银台。

  • 跳转支付不等于到账，请以订单状态和余额为准。
  • 未支付订单在创建后短时间内可按同账户、套餐与支付方式复用，不会无限延长。
  • 会话保存在同源服务端，浏览器只持有登录 Cookie；服务重启或会话到期后需要重新登录。
打开个人中心 →

网站分享图只含诗词

创作结果与作品详情都可以在浏览器绘制 PNG。分享图沿用纸色、边框与品牌底纹，包含作品标题、词牌与正文，不包含原照片。绘制使用站点内的文楷网页字体；失败时仍可阅读和复制文字，并可重绘分享图。

客户端

本机创作、历史与照片保存

客户端适合希望自备模型、把结果写回照片，或在本机保存完整历史的用户。源码支持 Android、iOS、HarmonyOS（华为鸿蒙）、Linux、macOS 与 Windows；当前公开下载以 Android 正式包为准，其他平台以发布页状态为准。

查看下载与发布状态

安装与平台

在下载页选择适合设备的安装包，并核对系统要求。尚未发布的平台会明确标注。

Android 客户端要求 Android 8.0 及以上；保存副本到系统相册需要 Android 10 及以上。iOS、HarmonyOS、Linux、macOS 与 Windows 的系统版本、架构及安装方式，以对应发布说明为准。

选择生成方式

客户端支持两种生成方式，按设置中的实际入口选择：

自定义模型

填写模型服务提供的 API key 与 Base URL，探测可用模型后选择支持图像输入的视觉模型。探测只返回模型列表，不会确认模型是否支持图像。服务可用性与计费由你配置的服务决定。

官方服务

在部署启用官方服务时，可登录账户或使用本机游客身份，查看可用次数并提交官方生成。官方服务与自定义模型不会在失败后自动切换。

先确认照片会发往哪里

自定义模型时，Base URL 决定请求发往的服务；官方服务则发往图赋官方后端及其模型服务。请确认地址可信，并妥善保管 API key。

查看模型与费用说明 →

为照片选择一种表达

选择一张照片后先在本机预览，再开始生成。选图本身不会调用模型。一次处理一张照片。

  • 诗：可选择绝句、律诗、单句等体裁。
  • 词：按词牌创作。
  • 纯照片信息：只生成照片标题、描述与标签。

生成后先阅读结果。标题与正文支持复制；构图建议单独展示，不写入图片元数据。格律与用韵是创作引导，不保证严格符合。Android 与鸿蒙可从相册分享单张照片到 App。

保存副本，或选择覆写

照片信息可写入元数据。请根据是否需要保留原图，选择对应保存方式。

保存副本

另存一份带有诗词、描述与标签的照片，保留源文件。Android 保存到系统相册需要 Android 10 及以上。

覆写源文件元数据

在支持的平台与照片来源上，明确选择后更新原图元数据。Android 仅适用于可解析的本地图库图片，并可能需要系统授权；Photo Picker 或云端来源可能无法覆写。HarmonyOS 与 iOS 当前不支持覆写；macOS 覆写的是选中的本地文件。

覆写前建议备份原图，并在保存后核对结果。

本机历史与分享

  • 搜索与详情：在本机历史中检索记录，打开详情回看创作内容；支持喜欢、收藏、回收站与恢复。
  • 查看原图：从记录打开对应原图；原图需要仍然存在且可访问。
  • 删除记录：整理本机历史。移入回收站超过 30 天后，读取历史时会清理；删除本机记录不等于删除模型服务可能保留的数据。
  • PNG 分享图：将已有诗词在本机排版为图片，供保存与分享；不包含原照片。没有诗词正文的纯照片信息结果不能生成诗词分享图。

本机历史不是云端备份，也不会与网站作品集自动同步。更换设备、清理应用数据或卸载前，请自行备份需要保留的内容。

界面语言与诗词用字，分别设置

客户端界面支持七种语言：简体中文、繁體中文、英语、日语、韩语、越南语、泰语。

诗词正文支持简体和繁体中文，默认繁体。界面语言与诗词用字分别设置；切换界面语言不会自动改变诗词用字。网站当前固定提交简体中文官方生成，不提供这项设置。

本机保存，不等于全程离线

请把“结果保存在哪里”和“生成请求发往哪里”分开理解。网站与客户端都会在生成时把照片内容发送给相应服务。

网站在线创作
选图后在浏览器重编码并移除 EXIF，点击生成后才上传。官方服务及其模型服务会收到处理后的照片。历史启用后，压缩照片与诗词会在服务端保留 90 天；浏览器不会把图片或分享图写入本地持久存储。
客户端自定义模型
所选照片及生成所需内容会发送至你配置的模型服务。数据保留、使用方式与费用由该服务的政策决定；请在发送前阅读并确认。
客户端官方服务
上传前会清理 EXIF/GPS，再提交官方生成。这能减少位置等元数据外泄，不能消除照片画面本身可能包含的个人信息。
本地模型与其他联网
自行部署的视觉模型是否继续调用上游，取决于部署方式。Android 的更新检查、模型探测、登录、查余额和购买也可能联网。本机历史不意味着应用完全不联网。
分享前再确认一次
发送照片或分享 PNG 前，确认愿意公开的文字、画面与元数据范围。网站与客户端的分享图都不包含原照片，但仍包含你确认过的诗词文字。
