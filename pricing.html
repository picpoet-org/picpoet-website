网页版使用官方生成服务与账户次数。套餐价格与额度以个人中心显示为准；支付跳转不等于到账。

客户端自定义模型

通常需要填写服务商提供的 API key。费用由对应服务商按 API 用量与计费规则收取，请在调用前确认模型价格、账户额度及可能产生的费用。

客户端本地模型

自行部署兼容的视觉模型服务，且该服务不再调用付费云端接口时，不产生云端 API 调用费用；硬件、电力和维护等运行成本仍由你承担。
