一张照片，一段心境

把眼前的风景，
留在诗里。

用 Picpoet 为一张照片创作诗或词，也可以只记录照片信息。让画面有文字，让回忆有处可寻。

从看见，到留住

照片之外，还有想说的话。

一次专注一张照片，按自己的方式留下文字与记忆。

01

写诗，也写眼前

选择诗、词或纯照片信息，生成标题、描述与标签。诗词支持简体、繁体中文，标题与正文可复制。

02

保存，留一份余地

将结果保存为照片副本，或在支持的来源和平台上选择覆写元数据。修改原图前，先留好备份。

03

回看，再分享

搜索本机历史、查看详情与原图，按需删除记录。把照片与文字制作成 PNG 分享图，分享当时的心境。

按你的习惯创作

模型由你选，
语言随你定。

在设置中填写 API key 与 Base URL，探测可用模型。界面提供简体中文、繁體中文、英语、日语、韩语、越南语和泰语七种语言；诗词内容单独选择简体或繁体中文。

本机历史不等于离线生成。使用云端视觉模型时，所选照片会发送至你配置的模型服务；服务商的数据处理政策与费用也需要一并了解。
